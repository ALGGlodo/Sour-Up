# Sour-Up
SOUR UP 🍬  A playful, high-energy landing page for SOUR UP — a candy brand serving bold, sour-fruit gummies for kids and teens who chase big flavor. Built from a custom Figma design and hand-coded to learn React fundamentals from the ground up.

🎯 Purpose

SOUR UP's website exists to introduce the brand, showcase its best-selling flavors, and build trust through real customer reviews — all while capturing the loud, playful, "dares you to try it" energy of the product itself. This project doubles as a hands-on learning build: every section was coded manually (no UI framework shortcuts) to strengthen core React, CSS, and animation skills.

👥 Target Audience
Primary: Kids and teens looking for bold, tangy, fun snacks
Secondary: Parents/guardians making the purchase, drawn in by real-fruit and gluten-free messaging
Anyone who enjoys playful, candy-forward branding and impulse-buy snack shopping online
🛠️ Tech Stack
Tool	Purpose
React	Component-based UI structure
Vite	Fast dev server and build tooling
Plain CSS	Hand-written, component-scoped stylesheets (no utility framework)
Motion (Framer Motion)	Scroll-triggered and floating animations
Lucide React	Icon set (stars, chevrons, shopping bag, etc.)
Google Fonts	Fredoka (headings) + Poppins (body text)
🎨 Design System
Colors: 
#FF2D78 (pink), 
#E2F200 (green), plus black and white for contrast
Typography: Fredoka for bold, rounded headings; Poppins for readable body copy
Visual language: hard offset shadows, bold pill badges, high-saturation color blocking, and snappy hover/scroll animations — designed to feel loud, playful, and tactile rather than soft or corporate
📄 Sections
Header/Nav — logo, navigation links, cart icon
Hero — headline, CTA, animated floating product shot, social proof pill
Bento Grid — responsive asymmetric grid highlighting brand imagery and facts
Products — best-seller flavor cards with ratings, pricing, and add-to-cart CTA
Ticker — infinite-scrolling strip mixing flavors and product facts (gluten-free, real fruit, less sugar)
Reviews — customer testimonials paired with their order details
🚧 Status

Actively in development — landing page first, with additional pages planned to follow using the same design system and component patterns.
